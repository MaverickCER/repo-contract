UnknownCheckIdError class

RunRepoContractOptions.checks (a partial-run request) names a check id that doesn't exist in the configured checks. Unlike a dependsOn id (already validated to exist by validateRepoContractConfig before any run starts), options.checks is only ever checked once runChecks actually resolves it -- there is no earlier structural-validation pass for it.
