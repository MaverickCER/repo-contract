DependencyDeclaredLaterError class

A check's dependsOn names a check declared *later* in the same checks object. dependsOn may only reference a check declared earlier -- see CheckDefinition.dependsOn's own doc comment. Declaration order doubles as the required topological order, so this is the only way an invalid dependency graph can arise; a real cycle is structurally impossible once every edge points backward. Thrown synchronously, before any check spawns.
