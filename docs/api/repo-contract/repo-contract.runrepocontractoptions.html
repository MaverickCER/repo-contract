RunRepoContractOptions interface

Optional per-run controls for runRepoContract.

Signature:

export interface RunRepoContractOptions

Properties

Property

Modifiers

Type

Description

checks?

readonly

string[]

(Optional) Restrict this run to only these check ids (and whatever they dependsOn, transitively). Every configured check runs when omitted.

signal?

readonly

AbortSignal

(Optional) Abort the entire run. Checks already in flight are terminated; checks not yet started never spawn. Every configured check still receives a well-formed evidence entry (status: "aborted") and still has its policy invoked.
