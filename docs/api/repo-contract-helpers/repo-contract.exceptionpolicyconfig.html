ExceptionPolicyConfig type

A full exception-policy configuration, keyed by classification group (e.g. a tool name, or a suppression domain). The core never invents the names "domain"/"rule"/"severity"/ "exceptionType" -- those are every consumer's own vocabulary, expressed here purely as { group, category } (see ExceptionClassification).

Signature:

export type ExceptionPolicyConfig = Readonly<Record<string, ExceptionCategoryGroup>>;
