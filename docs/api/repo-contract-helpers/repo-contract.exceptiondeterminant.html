ExceptionDeterminant interface

One record's resolved policy verdict, and (for "insufficient") which required fields are still empty. Never published as a batch/matched-vs-unmatched shape -- matching a finding to a record stays entirely check-owned (each check reconciles its own findings against its own registry via reconcileExceptions).

Signature:

export interface ExceptionDeterminant<TRecord>

Properties

Property

Modifiers

Type

Description

missing

readonly

readonly string[]

Every required field (by name) still empty on record, in the resolved policy's own requirements order. Always [] for "forbidden"/"permitted".

record

readonly

TRecord

The record this determinant was computed for, returned verbatim.

verdict

readonly

ExceptionVerdict

"forbidden": never permitted. "insufficient": exception-eligible, but missing is non-empty. "permitted": every required field is filled in (or the resolved policy was "allowed").
