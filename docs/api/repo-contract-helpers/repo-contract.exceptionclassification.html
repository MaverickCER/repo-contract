ExceptionClassification interface

One classification a record is evaluated against -- deliberately just { group, category }, never domain/rule/severity/exceptionType or any other consumer-specific vocabulary. A consumer maps its own domain concepts onto this shape at the call site (e.g. suppression-governance's { group: record.domain, category: rule } per suppressed rule; security-socket's { group: "socket", category: normalizedSeverity }) -- the core itself never interprets group/category beyond using them as lookup keys into an ExceptionPolicyConfig.
