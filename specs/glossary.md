# Glossary

The same word means different things in the different repositories of the toolkit
(`repo-contract`, `internal-package-contract`, `env-cap`, `data-cap`). This page fixes each use.

| Term          | In `repo-contract` / IPC                                                                                                                                                                                                                                 | In `env-cap` / `data-cap`                                                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Evidence**  | What one check _executed_: the command, exit code, output, timing (`CheckEvidence`, and the whole-run `Evidence` document). A record of what happened.                                                                                                   | The composed fact model of the capabilities a package declares and their consumers (`EvidenceModel`): ownership, expiry, consumers, findings. A record of what is _declared_. |
| **Verdict**   | What the repository's own policy concluded about the evidence of every check (`Verdict`): pass, warn or fail with a rationale.                                                                                                                           | Not used. A capability _report_ lists findings; it does not pass or fail a run.                                                                                               |
| **Contract**  | A repository's set of checks, run by `runRepoContract` (in IPC, the standard every package satisfies).                                                                                                                                                   | The declared capabilities of a package (`createEnv` / `createData` results).                                                                                                  |
| **Manifest**  | Not used.                                                                                                                                                                                                                                                | `env-cap`: the generated runtime input the package validates against. `data-cap`: documentation-only; nothing reads it at runtime.                                            |
| **Exception** | A committed, reviewed record that a rule is deliberately broken or a check could not run, kept in a registry under `.repo-contract/exceptions/` ([IPC EXCEPTIONS.md](https://github.com/MaverickCER/internal-package-contract/blob/main/EXCEPTIONS.md)). | A `dynamicAccess` citation: a read the build-time scanner cannot see statically, declared with a reason. A different thing.                                                   |
| **Check**     | One command plus a policy that judges its evidence.                                                                                                                                                                                                      | A finding category in a report (for example an abandoned-capability finding).                                                                                                 |
| **Policy**    | The function that turns one check's evidence into a verdict.                                                                                                                                                                                             | The ownership and expiry rules a declaration states about itself.                                                                                                             |
| **Standard**  | The set of checks in IPC's `standardChecks()`.                                                                                                                                                                                                           | Not used.                                                                                                                                                                     |
| **Registry**  | An exception registry file.                                                                                                                                                                                                                              | Not used.                                                                                                                                                                     |

When a sentence in any of the repositories uses one of these words, it means the column of the repository
it appears in.
