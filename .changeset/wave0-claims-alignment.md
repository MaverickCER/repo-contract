`buildEvidenceManifest` accepts an optional `subject` (`{ commit, ref? }`) and seals it into the manifest's digest, so a manifest says what a full run looked at, not only that one passed; manifests without a subject are unchanged.

Gates widened: the `security-network` scan covers the shipped `bin/` as well as `src/` (one reviewed record: the CLI loads the project's own TypeScript for `affected`); every published barrel has a gzip budget (helpers 9 KiB, affected 23 KiB, metrics 5 KiB, both formats); `v8`/`c8`/`istanbul ignore` directives are governed suppressions with records, and `no-console` and `@ts-expect-error` disables need a record too; the Bun, Deno and Node consumer tests import every barrel and the Node one runs the CLI's `--help`; the TypeScript compat consumer imports every barrel; CI runs each example's main README command and checks its outcome; a `required` CI check stands for every job the ruleset could not name, and `contract` fails instead of skipping when `verify` or `lint` fails.

Documentation now matches the tooling and the gates behind it. RELEASING and CONTRIBUTING describe the real release rules: changesets are generated from `feat`, `fix`, `perf` and `revert` commits on `main` (pre-1.0: breaking → minor, the rest → patch), other commit types release nothing, and a maintainer merges the Version Packages PR. `repo-contract/affected` and `repo-contract/metrics` now appear in VERSIONING (Experimental), `docs/surface.json`, the skill, the architecture spec's five barrels, the API-baseline list and the ADR-governance path list. The mutation sentence names what is excluded and the static mutants that are not counted; the network-scan sentence says what is scanned where; the persistence paragraph covers the opt-in cache and run log. Stale references to minimatch, release-please, a Node 20 floor, a TypeScript 5 toolchain, "three barrels" and an OS matrix for the contract are corrected, and `init` is no longer the only CLI command the architecture spec describes.

The `benchmark-pr` job now fails on a worse growth class (`--gate`, judged against the last run on main and the last release), after posting the summary; the overhead ratio is reported but, at this suite's scale, fails only on a tenfold change (the measurements behind that are in `benchmarks/budgets.mjs`); the `performance-api-contract` suite measures again (its fixture's tsconfig lacked the `rootDir` TypeScript 6 requires, so every tier had failed silently since 2026-10-19). `npm run contract` writes an evidence manifest for its own passing full runs to `reports/evidence-manifest.json`.
